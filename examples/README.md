# examples

折叠前后的实测对比帧（M3 Max，同一 prompt / 同一对首尾帧 / 同一 seed，
唯一变量是「原版 20 步」vs「折叠 Turbo LoRA 4/6 步」）：

| 文件 | 帧位置 | 内容 |
|---|---|---|
| `frame_compare_mid.png` | 第 11 帧（中段） | 四联对比：基线 20 步 / 6 步 / 5 步 / 4 步 |
| `frame_compare_end.png` | 第 21 帧（结尾） | 同上四联对比 |

测试规格：512×512 / 22 帧 / seed 42。结论：6 步与基线视觉几乎无差；
4 步在慢速内容下可用（快速动作场景的运动区会有可感知涂抹）。

更多实测数据（耗时/内存/多档位矩阵）见 README 的配方表。
